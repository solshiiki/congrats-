# Poker Lab — Monte-Carlo Odds (RU)

Запустите файл `index.html` любым статическим сервером или через предпросмотр в редакторе.

- Выберите две карманные карты и при желании часть/весь борд
- Выберите число соперников и итераций
- Нажмите «Рассчитать» — идёт Монте‑Карло симуляция с прогрессом
- Правая кнопка мыши по слоту — очистка
- Кнопка «Случайная раздача» быстро создаёт полный стол

Технологии: чистые HTML/CSS/JS, без библиотек.
